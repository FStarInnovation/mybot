## LLM Wiki

Проект использует паттерн LLM Wiki (по Карпатому) для накопления и структурирования знаний.

- **Schema**: `wiki/SCHEMA.md` — правила, конвенции, воркфлоу
- **Index**: `wiki/index.md` — каталог всех страниц (читай первым при Query)
- **Log**: `wiki/log.md` — хронологический лог операций

### Операции

- **Ingest**: добавление нового источника → `wiki/raw/` → создание summary + entity/concept страниц → обновление index + log
- **Query**: поиск по index → чтение страниц → синтез ответа → (опционально) сохранение как новая страница
- **Lint**: проверка здоровья вики (противоречия, сироты, пробелы)

### Правила

1. Никогда не модифицируй файлы в `wiki/raw/`
2. Всегда обновляй `wiki/index.md` при создании/удалении страниц
3. Всегда записывай в `wiki/log.md` при выполнении операций
4. Каждая wiki-страница должна иметь YAML frontmatter и секцию "See also"
