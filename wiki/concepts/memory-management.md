# Управление памятью

Система использует двухуровневую архитектуру памяти для управления контекстом диалога.

## Краткосрочная память (Redis-Short)

- **Хранилище**: Upstash KV-Store
- **Объём**: последние 20 реплик
- **TTL**: 2 часа
- **Назначение**: оперативный контекст текущего разговора, быстрый доступ

## Долгосрочная память (Supabase chat_log)

- **Хранилище**: Supabase Postgres
- **Расширение**: pgvector для векторного поиска
- **Назначение**: хранение полной истории и семантический поиск по прошлым диалогам

## Принцип работы

Memory Manager на стороне Laravel Cloud объединяет оба уровня: сначала загружает последние реплики из Redis для текущего контекста, затем при необходимости дополняет релевантными фрагментами из долгосрочной памяти через векторный поиск.
