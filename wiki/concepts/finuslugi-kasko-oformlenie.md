# Оформление полиса каско — процесс

5-шаговый процесс оформления каско через ЛК агента Финуслуг.

## Краткая схема

```
Госномер → Параметры авто/водителей → Выбор СК → Заполнение данных → Осмотр авто → Оплата → Полис
```

## 5 шагов

| Шаг | Действие | Кто делает |
|---|---|---|
| 1 | Расчёт: госномер + параметры | Агент |
| 2 | Выбор предложения СК | Агент + клиент |
| 3 | Заполнение данных + документы | Агент |
| 4 | Осмотр авто через приложение СК | Клиент |
| 5 | Оплата + получение полиса | Агент или клиент |

## Ключевые нюансы

- **Цена предварительная** — может измениться на 10–30% после полной формы
- **Мини-каско** — без документов, меньше этапов
- **Полное каско** — нужны фото ПТС/СТС + паспорт + ВУ всех водителей
- **Если нет предложений** — «Подать заявку», менеджер сделает расчёт
- Готовый полис — в «Черновики и продажи» + на email клиента
