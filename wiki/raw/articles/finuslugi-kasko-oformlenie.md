# Как оформить полис каско — Школа Агента Финуслуги

Источник: https://agents.finuslugi.ru/app/agent_school/c040b1c6-5dd1-46a4-a1b3-6f444b2caa8b

## Шаг 1. Начало работы

1. На главной в блоке «Рассчитать» → выбрать «Полис каско или мини-каско»
2. Ввести госномер → автоподгрузка: марка, модель, мощность, год, тип кузова, рыночная стоимость
3. Вручную: тип КПП, город, участие в ДТП за последний год → «Далее»
4. Дата рождения и пол страхователя
5. Добавить водителей (дата рождения, начало стажа, пол) — каждого отдельно
6. Контакты агента: имя и телефон → «Далее»

## Шаг 2. Выбор предложения СК

- Система показывает список СК с ценой и вознаграждением агента
- Кнопка «i» → детали программы, покрываемые риски, пример полиса, КИД
- Если предложений нет → «Подать заявку» → менеджер сделает расчёт и пришлёт предложения
- ⚠️ Цена полного каско может отличаться на **10–30%** после заполнения полной формы
- Выбрать → «Выбрать»

## Шаг 3. Заполнение данных

### Полис
- Дата начала действия

### Транспортное средство
- Пробег
- Серия, номер, дата выдачи СТС/ПТС/ЭПТС
- Срок владения
- Авто в кредите?
- 📎 Фото/скан ПТС или СТС/ЭПТС *(только для полного каско, мини-каско без документов)*

### Страхователь
- Паспортные данные + адрес регистрации
- 📎 Фото/скан паспорта

### Водители
- ФИО, серия/номер ВУ, дата выдачи
- 📎 Фото/скан ВУ каждого

### Контакты
- Email и телефон страхователя → «Далее»
- Проверить данные → «Далее»

## Шаг 4. Согласование условий

- Запрос уходит в СК для оценки рисков
- Клиент проходит **осмотр авто** через приложение СК (фото по инструкции)

## Шаг 5. Оплата и выпуск полиса

- СК формирует ссылку на оплату
- Способы:
  - Скопировать ссылку → отправить клиенту
  - Оплатить в ЛК → «Перейти к оплате» → данные карты
- Полис приходит на email + доступен в «Черновики и продажи»

## Отличия: полное каско vs мини-каско

| | Полное каско | Мини-каско |
|---|---|---|
| Документы | Нужны (ПТС/СТС/паспорт/ВУ) | Не нужны |
| Этапов больше | Да | Нет |
| Осмотр авто | Да | — |
