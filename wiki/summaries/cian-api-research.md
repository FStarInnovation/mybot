# CIAN API — Исследование

Полное исследование API и способов извлечения данных с CIAN.RU.

## Два способа получения данных

| Задача | Способ | Метод |
|---|---|---|
| Поиск по фильтрам | Search API | `POST /search-offers/v2/search-offers-desktop/` |
| Данные одного объявления | SSR HTML-парсинг | `GET /sale/flat/<ID>/` + `offerData` из `<script>` |

**Ключевое**: оба способа требуют **браузерные куки CIAN**. Без них WAF → 403.

## Архитектура CIAN

- Основные данные (цена, площадь, адрес, фото) — **встроены в HTML через SSR**, без отдельного API-запроса
- Дополнительные данные (избранное, чат, карта, оценка) — асинхронно через REST
- Базовый URL: `https://api.cian.ru/`
- Приложение: `frontend-offer-card`

## Масштаб данных (март 2026)

~507 000 объявлений по 3 регионам (Москва + МО + СПб):
- Продажа квартир: 114 092
- Аренда квартир: 181 153
- Коммерция (продажа+аренда): 119 015
- Загородная (продажа+аренда): 93 175

## Структура продавцов (выборка март 2026)

| Тип | Доля | ~Кол-во (продажа кв.) |
|---|---|---|
| Застройщики (новостройки) | ~34% | ~33 000 |
| Частные риелторы | ~47% | ~45 600 |
| Агентства | ~13% | ~12 500 |
| **Собственники** | **~15.6%** | **~17 800** |

*Собственники не попадают в топ выдачи — не платят за продвижение.*
